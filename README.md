# homebrew-skilldock

[SkillDock](https://github.com/dosuser/skilldock)용 Homebrew tap.

## 설치

```bash
brew tap dosuser/skilldock
brew install --cask skilldock
```

## 업데이트

```bash
brew upgrade --cask skilldock
```

## 삭제

```bash
brew uninstall --cask skilldock
# 설정 파일까지 지우려면
brew uninstall --zap --cask skilldock
```

Cask 정의: [`Casks/skilldock.rb`](Casks/skilldock.rb)
