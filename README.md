# homebrew-skills-on-menu

[SkillsOnMenu](https://github.com/dosuser/skills-on-menu)용 Homebrew tap.

## 설치

```bash
brew tap dosuser/skills-on-menu
brew install --cask skills-on-menu
```

## 업데이트

```bash
brew upgrade --cask skills-on-menu
```

## 삭제

```bash
brew uninstall --cask skills-on-menu
# 설정 파일까지 지우려면
brew uninstall --zap --cask skilldock
```

Cask 정의: [`Casks/skills-on-menu.rb`](Casks/skills-on-menu.rb)
